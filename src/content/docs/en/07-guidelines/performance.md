## Topics

Core Web Vitals, rendering performance, resource loading, HTML quality, and technical reliability.

## Candidate questions

- Which technical failures prevent a target client from reaching or extracting content?
- Are performance metrics outcomes, controls, or confounders in a given study?
- Can any measured effect be attributed specifically to frontend performance?

No GEO/AEO ranking or citation benefit is assumed. Any recommendation must distinguish user-performance rationale from measured generative-search outcomes.
