## Topics

HTML validation, structured-data validation, accessibility testing, crawler-rendering tests, content-extraction tests, retrieval evaluation, and regression testing.

## Candidate questions

- Which checks validate syntax or standards conformance, and which measure user or retrieval outcomes?
- How are crawler/rendering checks repeatable across time and systems?
- What regression fixtures and thresholds are justified by observed variance?

No test suite or threshold has been finalized. Avoid treating a passing validator as evidence of improved retrieval or answers.
