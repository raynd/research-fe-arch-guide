## Topics

Content modeling, document boundaries, section structure, heading-context relationships, self-contained sections, content chunkability, and metadata.

## Candidate questions

- Which structures preserve necessary context after parsing and chunking?
- How do coherent boundaries affect retrieval for a defined corpus and query set?
- Which authoring constraints help machine extraction without harming human usability?

No guideline is approved. See [EXP-004](/en/05-experiments/exp-004/) and avoid assuming that DOM boundaries match any external system's chunks.
