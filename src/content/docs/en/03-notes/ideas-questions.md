All items here are questions or ideas, not conclusions.

## Measurement design

- Which content extraction tools expose enough intermediate output to compare variants?
- How should retrieval quality be measured when a provider's index and ranking are opaque?
- Can answer quality and citation support be separately annotated with acceptable agreement?
- What number of pages, queries, and repeated runs is feasible for a pilot?

## Controls and confounders

- How will content equivalence be maintained across SSR, SSG, and CSR variants?
- How should caching, request timing, JavaScript wait time, and page errors be controlled?
- Which accessibility or validation checks are controls rather than measured outcomes?

## Workflow

- Define literature-search databases, queries, date range, inclusion/exclusion criteria, and screening log.
- Select and version the tools, query set, datasets, and annotation rubric.
- Pilot measures before committing to a confirmatory comparison.
