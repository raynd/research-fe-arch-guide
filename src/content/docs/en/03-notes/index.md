## Formats

- Use **Markdown** (`.md`) for free-form notes, journal entries, brainstorming, and meeting records.
- Use **Markdoc** (`.mdoc`) for structured hypotheses, experiments, and future research objects using validated tags.

## Note-taking practice

Give each note a date and descriptive title. Mark unverified observations as such. Add links to papers, hypotheses, experiments, or findings when available; retain the exact source and context for quotations.
