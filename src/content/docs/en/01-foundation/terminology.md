---
title: Terminology & Definitions
description: Working definitions to keep research claims precise and consistent.
---

These are working definitions for this project, not claims about the internal design of any particular provider.

| Term              | Working definition                                                                                                                                                        |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GEO               | Generative Engine Optimization; practices proposed to improve how content is surfaced or used by generative search. Define the specific outcome in each study.            |
| AEO               | Answer Engine Optimization; practices proposed to improve the availability or use of content in answer-oriented systems. Define the system and outcome when measuring it. |
| CSR               | Client-side rendering, where browser-side JavaScript generates or substantially populates page content.                                                                   |
| SSR               | Server-side rendering, where HTML is rendered for a request before it reaches the browser.                                                                                |
| SSG               | Static site generation, where HTML is generated ahead of a request.                                                                                                       |
| RAG               | Retrieval-augmented generation: a system pattern that supplies retrieved information to a generative model.                                                               |
| Extraction        | Converting source content into structured or textual representations usable by a downstream process.                                                                      |
| Retrieval         | Selecting candidate documents or passages for a query.                                                                                                                    |
| Answerability     | The degree to which available content supports a response to a specified question, as operationalized by a study.                                                         |
| Citation accuracy | Whether a citation identifies a source that supports the attributed claim, according to a declared rubric.                                                                |
| Evidence          | A traceable source or observation relevant to a claim; strength depends on methods and applicability.                                                                     |

Revise definitions if literature uses terms differently; preserve the source-specific meaning when reporting a study.
