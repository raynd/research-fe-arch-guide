---
title: Reproducibility
description: Reproduction requirements and archival checklist.
---

Before calling an experiment reproducible, retain:

- Frozen protocol, variants, source content, data, and query set with version identifiers.
- Build and runtime requirements, tool versions, and non-secret configuration.
- Exact execution steps, run date, environment, and number of repetitions.
- Raw outputs and transformations from response through analysis.
- Metric definitions, annotation instructions, scripts, and any manual decisions.
- Deviations, failed runs, missing observations, and known external-system changes.
- Sharing, licensing, privacy, and access constraints.

Keep credentials and sensitive data out of the repository. Where external services prevent exact reproduction, state the limitation and preserve the available request/response record.
