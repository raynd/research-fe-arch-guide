title: Test Cases & Test Data
description: Dataset and test-case planning for controlled comparisons.
---

No experiment dataset has been created. Before execution, maintain a local, versioned dataset record containing:

- Stable test-case ID and target concept or question.
- Source text, expected facts or extraction fields, and source provenance.
- Content-equivalent HTML/rendering variants and checksums.
- Query set, expected relevant passage/document, and relevance rationale.
- Annotation instructions, reviewer agreement process, and adjudication.
- License, privacy review, exclusions, and changes between dataset versions.

Keep test content synthetic or appropriately licensed where possible; do not imply that a small test corpus represents the public web.
