---
title: Terminologie und Definitionen
description: Arbeitsdefinitionen für präzise und konsistente Aussagen.
---

Dies sind Arbeitsdefinitionen für das Projekt, keine Aussagen über die interne Implementierung bestimmter Anbieter.

| Begriff           | Arbeitsdefinition                                                                                                                                                                            |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GEO               | Generative Engine Optimization; vorgeschlagene Maßnahmen, um Inhalte in generativen Suchsystemen sichtbar oder nutzbar zu machen. Das konkrete Ergebnis ist je Studie festzulegen.           |
| AEO               | Answer Engine Optimization; vorgeschlagene Maßnahmen zur besseren Verfügbarkeit oder Nutzung von Inhalten in antwortorientierten Systemen. System und Ergebnis sind bei Messungen anzugeben. |
| CSR               | Client-Side Rendering: JavaScript im Browser erzeugt oder ergänzt wesentliche Seiteninhalte.                                                                                                 |
| SSR               | Server-Side Rendering: HTML wird vor der Auslieferung an den Browser für die Anfrage gerendert.                                                                                              |
| SSG               | Static Site Generation: HTML wird vorab und nicht erst für eine einzelne Anfrage erzeugt.                                                                                                    |
| RAG               | Retrieval-Augmented Generation: Systemmuster, bei dem ein generatives Modell Informationen aus abgerufenen Quellen erhält.                                                                   |
| Inhaltsextraktion | Überführung von Quellinhalten in strukturierte oder textuelle Darstellungen für nachgelagerte Prozesse.                                                                                      |
| Informationsabruf | Auswahl von Kandidatendokumenten oder -passagen für eine Query.                                                                                                                              |
| Beantwortbarkeit  | Grad, zu dem verfügbare Inhalte eine Antwort auf eine bestimmte Frage stützen, operationalisiert durch die jeweilige Studie.                                                                 |
| Zitiergenauigkeit | Maß dafür, ob eine Zitierung eine Quelle nennt, die die zugeordnete Aussage gemäß festgelegtem Bewertungsraster stützt.                                                                      |
| Evidenz           | Nachvollziehbare Quelle oder Beobachtung zu einer Aussage; Aussagekraft hängt von Methodik und Übertragbarkeit ab.                                                                           |

Definitionen sind anzupassen, wenn die Literatur Begriffe anders verwendet. Bei der Wiedergabe einer Studie bleibt ihre jeweilige Bedeutung erhalten.
